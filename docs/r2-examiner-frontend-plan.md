# R2 考官端前端方案

考官登录后的主线是「找考生或创建房间 → 打开已完成的考试 → 按题看分与证据 → 确认或调整评分」。一行代表一间房、一名考生和一次考试。创建表单里的考生用户名是供辨认的显示名，入场凭证由平台生成。

接口与状态以同期 [后端方案](r2-examiner-backend-plan.md) 为准。前端可先用契约样例开发，联调时切换到真实接口。

## 页面一：考试房间列表

- 沿用考官登录。考官从 `/admin/r2` 进入答卷列表，选择「考试房间与入场凭证」进入 `/admin/r2/rooms`。四题答卷另有分项评定和整场确认发布入口。
- 列表显示考生名、考试名称、考试状态、入场截止时间和操作。考试状态区分待入场、已入场、考试中、已完成、入场已过期。已完成行旁另显示「评分中／待复核／已确认」等评分状态。默认按创建时间由新到旧，支持状态筛选、按考生名搜索和分页。历史记录和归档仍可核对。
- 每行的「入场凭证」默认折叠，展开时按需请求明文，支持复制和收起。已过期或已入场时显示原因。历史房间若没有可回显的凭证，显示「旧凭证无法查看」。刷新、离开页面或折叠后清除当前明文。
- 点「创建房间」打开小表单，填写考生名、选择入场截止日期时间，显示当前四题试卷及版本。解释「考生在截止前首次入场即可，作答时间按考试规则另计」。明确显示时区。提交成功展示考生名、截止时间、通用入口与凭证，提供复制凭证和复制入场信息两个动作。考官自行转发。
- 创建失败保留表单。试卷版本更新时展示新版并让考官确认后重试；响应丢失时使用原请求键核对。加载中禁用重复提交。列表提供空态、失败重试。已完成行可进入详情，进行中房间的进度直接在列表查看。

## 页面二：考试结果

页面从概览到细节分三层，返回列表保留搜索、筛选与页码。

| 层级 | 显示内容 |
|---|---|
| 考试概览 | 考生名、考试状态、提交时间、四张题目卡片，各显示题型、得分状态和已确认分数 |
| 单题详情 | 固定题面、提交内容及得分分项。前两题展开五问或审阅报告和对应评分。后两题展开客观测试组、两道问答、过程评分，以及对应证据 |
| 证据与复核 | 查看完整过程记录、最终代码差异及评分依据。固定位置显示AI原分、调整值、封顶与最终分，提供一次性确认操作 |

未评分用「待评分」或「需复核」表达，真实零分显示 0。已完成但尚有组件未出分时，仍可读题面、答卷和已得分项。失败或需评分负责人处理时，显示原因、答卷 ID 和刷新入口；分数就绪后开放确认。按现有规则展示私有测试的分组结果和面向评阅的解释。整场汇总展示四题状态，整场加权分等待统一规则。

### 过程记录

从单题详情进入「作答过程」。默认按时间展示该题所有对话，可按会话筛选并通过证据引用定位。使用已有 Markdown 渲染及安全规则，保留候选人和 Agent 的身份区别。测试回执、审批同意或拒绝及工具结果按发生位置插入。实际用过的代码变更以可折叠的 unified diff 展示文件、行号和变更者；待批提案与实际写入有独立标签。最终代码差异单独提供。长记录分页加载，预览裁切或旧记录缺档时明确提示范围。第一题可看探索历史；第二题本身禁用 Agent，说明该题无 Agent 对话。

### 一次性复核

建议后两题各有一次复核机会，调整该题主观部分，整数 −10 至 ＋10，调整后主观保持 0–30，Bug 题仍按规则封顶。页面以接口给出的合法区间、封顶及试算为准。此前的 70＋20＋10 作为默认显示口径；若委员会为代码风格另定分，后端随评分版本返回对应分项。

- 「确认原分」和「调整分数」均显示最终确认对话框，写明提交后该题复核锁定。调分必须填写理由；调 0 分走确认原分路径。
- 提交前同时展示原分、拟调值、封顶前后结果；有封顶时明确调分可能不改变最终分。
- 成功后展示「已确认原分」或「已调分并锁定」，常显复核人、时间和有调分时的理由。不同状态配文字及图标，颜色用来辅助识别。
- 请求超时先查该题复核结果；另一位考官抢先保存时显示已确认结果，评分更新冲突时展示新版分项供重新核对。刷新后以服务端状态为准。

## 前端开发及验收

1. 先交付列表、创建、凭证折叠与复制，覆盖同名考生、过期、首次入场和响应丢失。
2. 接入考试详情、四题卡片、分项和回放。用有多会话的答卷检查排序和引用，分别核对被拒补丁与成功写入。用一份旧答卷检查「仅有差异预览」等缺档状态。
3. 接入复核确认，以完整样卷演示调分、维持原分、刷新后锁定及双标签冲突。用封顶样卷对照后端试算。键盘可操作表单和确认框，桌面与窄屏均能查看分项，长 diff 在容器内横向滚动。

## 本地预览与走查结果

预览入口为 `/preview/examiner/`，由前端 Vite 开发服务提供。示例房间、答卷、凭证和评分均为模拟数据，创建与复核记录只存当前浏览器。预览覆盖独立的考官流程，沿用应用的登录、真实分页、试卷绑定和服务端并发锁定留待接口联调。

Chrome 已走查创建、复制、折叠凭证、评分中状态、展开拒绝提案和已写入的 diff、调分理由校验、调分确认、原分确认、封顶及刷新后锁分。390 px 宽度下详情页未出现页面级横向溢出。现有前端单元测试 7 项通过。

走查后固定三条交互：创建成功即展开新房间凭证，方便紧接着复制；答卷已交但评分尚未完成时，保留已有评分和证据，稍后再复核；封顶题的确认框并列显示封顶前后分数，拟调分不改变最终分时单独提示。

真实数据联调优先验证两处：同一考生多间房时是否需要考官自定义房间备注，以及长回放能否从评分依据直接跳到对应事件。预览里的短记录只能验证展开和说明，无法验证真实事件定位和分页。
