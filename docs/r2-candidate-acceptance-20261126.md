# 四题考生端验收 · 2026-11-26

四题八环节已在独立联测实例上走通。手动交卷和全部到时各留存四份回执。正式验收仍有一项功能缺口：后两题的问答页能回看编辑器保存和“运行并记录测试”的记录，但不能完整回看本题 Agent 对话、审批、Agent 编辑和普通终端操作。

## 实测环境和样卷

实例使用 `codex/r2-grading-jobs` 的四题后端（`d66e3b5`）、本轮修正的前端、独立 PostgreSQL 16（迁移至 `0014_stage_grading_jobs`）、实际模型服务与 runsc 沙箱。问答使用显式选定的 `examples/r2-interview-draft.json`。本机 5196 是设计评审页。5197 通过 SSH 转发到服务器的回环端口 18085，路径为 `/entry?mode=r2`。

手动场次使用新凭证，从浏览器入场后依次完成四题。后两题通过浏览器内的考生保存接口写入验收用代码，使用页面完成 Agent 编辑审批、运行测试、结束编程、填写问答和提交。后台逐份导出回执，对照问答页的代码摘要、编程环节 ID 和证据截止序号。

另用独立测试考生，在服务进程内推进测试时钟至各环节截止时间，沿用实际数据库、沙箱和封存代码。八个环节依次结束，四份回执均为 `expired`，每题最后保存的答案或报告均能导出。该轮没有在浏览器中等待 175 分钟。

## 方案第 10 节逐项核对

| 条目 | 本轮观察 |
|---|---|
| F01 入场与计时 | 准备前后均无作答截止时间，开始后绑定截止时间。后台核对八段净时长合计 175 分钟。恢复与截止时间持久化另有 PostgreSQL 回归验证。 |
| F02 探索权限 | 第一题读取源码、写入并恢复 `note.md`、实际调用只读 Agent。服务端拒绝提前取问答、写源码和开终端。 |
| F03 切换撤权 | 独立答题只读笔记，服务端拒绝调用 Agent。正在运行的调用被撤销、迟到调用被拒绝，由受控模型与沙箱回归覆盖。 |
| F04 草稿 | 浏览器恢复五问答案；第四题用同一凭证的两个标签页制造真实修订冲突，核对另一窗口答案后可选择保留本窗口草稿。 |
| F05 审阅报告 | 页面新增、移除、填写、刷新和提交成功。服务端接受“未发现问题”空报告，拒绝 6 条报告及单条 1201 字符。阅读阶段拒绝题干、源码写入、Agent 和终端。 |
| F06 编程与验证 | 第三题基线 1 项公开测试失败，第四题 2 项失败。两题均实际批准 Agent 编辑，在看到新增测试自身出错后修正并重跑，最终分别 2 项、3 项全过。手动触发封存和交卷。 |
| F07 审批与停止 | 第三题拒绝一次编辑后核对文件未改；刷新后恢复待审批状态，另一次批准的编辑写入文件，运行停止后后台留存 interrupted。问答页对这些事件的回看受 F09 缺口影响。 |
| F08 封存与旧权限 | 第四题通过普通终端启动后台任务后切换。第三、四题旧阶段的文件与对话接口均返回 PHASE_CLOSED。两工作区已 sealed，对应旧容器均已移除，离场后后台导出摘要与问答页一致。 |
| F09 证据回看 | 两道问答均可保存和刷新。逐页读取的记录与冻结代码摘要一致。两题均报告 partial / CAPTURE_GAP。实际发生的对话、审批未出现在记录中，普通终端命令也未进入回看。此项未通过。 |
| F10 封存异常 | 正常封存由浏览器验证。封存失败、重试、重启恢复和并发提交仅有受控故障及 PostgreSQL 回归证据，本轮未在浏览器封存途中重启预览服务。 |
| F11 完卷与离场 | 手动场次和受控到时场次各四份回执。手动场次交卷、刷新均显示离场页，考生请求评分任务接口返回 401。未在真实已发布成绩的场次重放。 |
| F12 题干和评分保密 | 对照四道独立问答的完整题干，未在生产前端脚本或两题归档的工作区文件中检出；冻结后各返回本题两问。考生须知仅预告主观题。真实考官发布前后的权限仍需随发布流程复验。 |
| F13 保存失败 | 第四题阻断答案保存后点击交卷，页面保留草稿，服务端仍在作答。恢复请求后成功提交；版本冲突时直接交卷也不会覆盖另一窗口。到时样卷保留最后确认的答案。 |

下一轮联调沿用相同操作：编程中发送一条消息、拒绝一次并批准一次编辑，从普通终端运行一次测试，再从验证页记录一次测试。刘婧瑶核对问答页逐项回看，陈弘毅按回执核对导出。已封存样卷继续保留其原始缺失状态。
