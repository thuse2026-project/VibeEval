## 本轮修复

- 工具参数不合法时反馈声明字段及安全的校验类型，允许有边界的自动修正，不把一次历史错误变成所有后续调用的永久失败。
- 为当前官方 DeepSeek Flash 预览显式启用 thinking，私下保留工具连续调用要求的 reasoning continuation，不向公共历史、压缩摘要或界面返回。thinking 计划保留配置的输出额度，避免推理和计划共用过小上限。
- 预览的窗口、序列化上限与压缩策略相互对齐；不扩大其他部署的默认上下文。连续读取时提示回到用户当前请求，不自动授予写入权限，也不要求只读问题强行改代码。
- 终端工具说明明确相对工作目录、测试直接执行及真实退出码。审批仍走现有权限检查。
- 保留 yellow 的安全 Markdown 展示；新增考官多阶段评分入口，详见 [评分说明](datasette-grading.md)。

这次证明两个指定流程可以完成，不证明所有题目或所有模型调用都稳定。第一题仍有较多检索，修改回合累计模型 token 计数约 140 万（多次请求重复上下文之和，不是单次上下文或实际账单）；效率、缓存命中和成本优化另行跟踪，不再为本次验收继续重复调用模型。
