# 仓库上手测验

五题，每题 20 分。请根据当前固定源码回答。

## Q1：项目结构（20 分）

请说明 TinyDB、Table、Query、Storage 分别承担什么职责，并说明数据库、表、文档之间的组织关系。回答应体现模块之间如何配合，不必列出全部类或方法。

## Q2：执行过程（20 分）

假设 db 是一个已打开的 TinyDB 对象，使用默认 JSONStorage，文件中已有合法数据。执行 db.all() 时，TinyDB 类并没有直接定义 all 方法。请说明这次调用怎样到达存储层、怎样得到返回结果。请给出关键函数及调用关系，无需描述操作系统底层文件调用。

## Q3：对象与数据组织（20 分）

在同一个 db 上依次执行 a = db.table('users')、b = db.table('users')、c = db.table('logs')。a 与 b 是否为同一个对象？a 与 c 是否为同一个对象？它们如何使用底层存储并区分数据？请根据实现解释，不必讨论并发或缓存。

## Q4：行为推断（20 分）

在全新的 MemoryStorage 数据库中依次插入 {'name': 'A', 'age': 20}、{'name': 'B', 'age': 17}、{'name': 'C'}，然后执行 db.search(Query().age >= 18)。结果包含哪些 name？第三条文档没有 age，为什么会得到相应结果？请结合查询条件求值过程解释。无需运行代码。

## Q5：扩展影响（20 分）

希望为 TinyDB 增加一种本地存储实现，保持调用方现有的 Table 增删改查接口。请说明需要遵守哪些存储接口约定、如何接入，以及你会检查哪些行为。只要求设计与验证思路，不需要编写实现，也不要求设计并发或事务。
