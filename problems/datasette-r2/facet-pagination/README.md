# 修复翻页后的筛选统计和链接

数据分析人员在表格第一页能看到正确的筛选计数。翻到第二页后，筛选项计数变小，有些选项也消失了。此时添加或移除筛选，链接有时还带着上一组结果的翻页位置，导致漏掉匹配数据。

- 普通列、日期和数组筛选项的计数，应来自当前业务筛选下的全部匹配记录。翻页位置只影响当前展示的行。
- 添加或移除筛选项，必须从新的结果集第一页开始，保留其他筛选条件、排序、每页大小及重复参数。取消最后一个筛选后，链接应正确移除该条件。
- 原本的数据分页、排序、非分页结果和无筛选行为继续工作。

允许修改 `datasette/facets.py`、`datasette/views/table.py`、`datasette/views/table_extras.py` 和 `tests/test_candidate.py`。公开测试使用固定的 SQLite 数据，可直接复现：

```sh
python -m unittest discover -s tests -p "test_*.py" -v
```

结束编程后，系统会固定当前代码并进入独立问答。
